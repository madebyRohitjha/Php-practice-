PHP Built-in Functions Assignment

Run with XAMPP:
1. Copy the php_functions_assignment folder into C:\xampp\htdocs\
2. Start Apache in the XAMPP Control Panel.
3. Visit http://localhost/php_functions_assignment/ in your browser.
4. Select a function from the index page.

There are 15 individual example pages: 5 string, 5 math, and 5 array functions.
